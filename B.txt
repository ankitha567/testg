Setting up Maven from ZIP on Windows

1. Extract the ZIP
   - Unzip the Maven folder to a location like:  
     C:\Program Files\Apache\Maven  
     (or any directory you prefer).

2. Set Environment Variables
   - Press Win + R, type sysdm.cpl, and hit Enter.  
   - Go to Advanced → Environment Variables.  
   - Under System Variables, click New:  
     - Variable name: MAVEN_HOME  
     - Variable value: C:\Program Files\Apache\Maven (your extracted folder path).  
   - Edit the Path variable → Add:  
     `
     %MAVEN_HOME%\bin
     `

3. Verify Java
   - Make sure JDK is installed and JAVA_HOME is set.  
   - Check with:  
     `bash
     java -version
     `

4. Verify Maven
   - Open Command Prompt and run:  
     `bash
     mvn -v
     `  
   - You should see Maven version, Java version, and OS details
